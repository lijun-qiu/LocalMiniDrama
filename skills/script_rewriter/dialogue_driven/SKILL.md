# 强对话驱动改写指南

本 skill 是默认「画面均衡」改写的可切换替代方案。更激进地用对白推进冲突，动作只留推动当前节拍所必需的部分。

## 与默认 skill 的差异

| | 默认 script_rewriter | 本 skill（dialogue_driven） |
|--|--|--|
| 叙述/动作 | 允许较完整的画面段落 | 日常戏：同一落点下可连续数个小动作；**打戏按一次交锋的结果写，不要按微动作拆场** |
| 情节推进 | 动作 + 对白共同推进 | 日常戏靠对白；动作戏靠可见招式节拍 |
| 台词密度 | 适中 | 对白戏高密度短句；打戏台词极少（喝骂/冲击句） |
| 旁白 | 少用 | 尽量不用；必要时用 `[VO]` |

## 改写原则

1. **保留核心情节**：不改变主线与角色关系
2. **对白即剧情（日常戏）**：冲突、信息、关系变化优先出现在台词里
3. **短句口语**：单句优先 ≤15 字，适合竖屏听感；禁止书面长句
4. **动作分级**：日常戏极简动作；**原文有打戏/追逐/肢体冲突时必须保留，不得改成纯对白**
5. **不写镜头语言**：禁止景别、角度、运镜（留给分镜拆解）
6. **按节拍切场**：一场是一个戏剧节拍（观众新知道一件事，或情绪转一次），目标 10–12 秒；禁止把同一节拍拆成多个场头。场尾可留半句钩子，集尾必须留未完成冲突
7. **整段改写**：原文从第一段写到最后一段，全部改成可拍场次，不得跳过开头或结尾

## 整段改写（硬性）

1. `content` 里的每一段都要进剧本，包括标题为「开篇钩子」「冷开场」「倒叙」「前史」的段落
2. 这些标题是要演的戏，不是提纲；必须改成 `## S01` 起的连续场次，按发生顺序先演
3. 禁止把开篇事件压成后文一句点名、一句回忆或一句旁白（例如只留「黑蛇。赵猛。小雨。」）
4. 开篇若是动作/打戏，按可见结果拆开，不得省略；同一次交锋的收尾（枪响后失去意识）不要再单独成场
5. 自检：原文开头的人物、地点、冲突，必须出现在剧本最前几场

## 动作 / 打戏（必须保留）

原文出现打架、追杀、闪避、压制、兵器交锋、车祸冲撞等**可见肢体冲突**时：

1. **不能删、不能改成嘴炮**：按可见结果拆成连续场次，而不是缩成一句「两人打了起来」
2. **一场一次交锋**：每场写清一次交锋的结果（扑上并刺出、格开并踹倒）。枪响、倒地、失去意识若是这次交锋的收尾，且按「时长估算」累加后不超过 12 秒，留在同一场
3. **打戏台词**：可无对白，或每场最多 1 句短喝骂/威胁；禁止边打边解释剧情
4. **动作写法**：主谓宾短句，写清谁对谁做了什么、结果是什么；不写内心、不写镜头
5. **与对白戏衔接**：打前可用 1 场对白引爆，打后用 1 场对白收口；中间打戏场次以动作为主
6. **日常戏不要套打戏**：醒来、看手机、照镜子、打字、攥拳不是交锋，禁止按「一个动作一场」拆

示例：

```
## S05 | 外景 · 巷口 | 深夜
人物：阿强、杀手

杀手扑上，匕首刺向阿强胸口。
阿强侧身格开，一脚踹中对方膝弯。
杀手：（怒）站住！
```

上面是一次交锋，不要再拆成「刺出」一场、「格开」一场。下一次交锋（夺刀、摔倒）才新开场。日常戏比这更密，不要按招式拆。

## 按节拍切场（硬性）

一场 = 一个戏剧节拍，不是一个镜头。节拍是「观众新知道一件事，或情绪发生一次转折」。看一眼、攥拳、放下手机、表情变了、眼神变冷、补一句决心，都不是节拍，不得单独成场。

### 时长估算（硬性）

估算表演时长时，只累加对白与动作，按下列口径：

- 短对白：6–15 字约 1.5–2.5 秒；16–25 字约 2.5–4 秒。
- 简单动作：1–2 秒；完整动作段：3–6 秒。
- 场景头、空行不计入表演时长。

一场目标 10–12 秒 = 本场对白秒数 + 动作秒数落在该区间。按上表累加后不足 10 秒：禁止单独成场，并进相邻且落点相同的场。明显超过 15 秒才拆。禁止凭感觉或按场次公式硬凑。

1. 先列出戏剧节拍（一句话一个落点），再一场一拍。禁止用 `总秒数 / 12` 去凑场数，禁止把同一节拍切匀。
2. 一场目标 10–12 秒（按上表估算），里面可以有连续几个小动作和 2–4 句短对白，只要通向同一个落点。例：吐完、站起来、照镜子、说「回来了」，是一场，不是四场。
3. 只有两种情况才拆场：按上表累加后这一场会明显超过 15 秒；或者里面有两个互不从属的落点（先看清日期，再决定去找人，应拆开）。
4. 禁止单独成场（必须并进相邻场）：
   - 只有反应没有新信息（闪回已演过的开篇、眼神变冷、抹脸、盯着屏幕）
   - 同一句话换个说法再说一次（「回来了」和「不是梦」）
   - 电话的拨号与通话内容拆开
   - 落点相同的连续两通电话（都是「确认人还活着」）——并成一场连打
   - 清单/备忘录/电脑文档的逐条或二次补字
   - 刚离开的房间马上返回只为说一句；情绪落款句（如「谁都不能死」）——并进计划场或电话场尾
5. 同地点不是拆场理由。换地点只在新地点自己有节拍时才新开场。连续多场都在同一地点时，先怀疑切碎了。
6. 同一计划、同一揭示只演一次，只留一个载体。禁止：备忘录写三步 → 闪回强化 → 电脑再写清单 → 再补一行。留最能打的那一次，其余删或并成一句动作。
7. 自检：
   - 删掉任一场后，如果情节和情绪都还在，这场就不该存在
   - 各场比的是信息量，不是动作次数
   - 用上表复核每场约 10–12 秒、未误超 15 秒、没有不足 10 秒的孤场
   - 通读场次落点列表：若出现两个相邻落点可写成同一句，必须合并

反例（禁止）：

```
## S08 | 内景 · 洗手间 | 清晨
人物：林北

林北看向镜子。
林北：回来了。

## S09 | 内景 · 洗手间 | 清晨
人物：林北

林北冲了把冷水。
林北：不是梦。
```

正例：

```
## S04 | 内景 · 洗手间 | 清晨
人物：林北

林北吐完，撑着水箱站起来，看向镜子。
镜中的脸年轻了五岁。眼神一点点变冷。
林北：回来了。不是梦。
```

再反例（禁止：同一计划多载体 + 反应场）：备忘录三步单独一场 → 闪回末世单独一场 → 电脑清单单独一场 → 补「谁都不能死」单独一场。应并成：备忘录一场（可收一句决心）；闪回/清单整段删。
## 输出格式

```
## S01 | 内景 · 咖啡厅 | 黄昏
人物：小明、小红

小明坐角落刷手机。门铃响。

## S02 | 内景 · 咖啡厅 | 黄昏
人物：小明、小红

小红：（笑）等很久了？
小明：（不抬头）还好。
小红：你又骗人。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头（与下游提取/分镜兼容，必须保留）
- `人物：A、B` — 本场出场角色，一行写完
- 动作行 — 独立自然段，极短；不要写成小说
- `角色名：（可选状态）台词` — 对白主轴
- `[VO] 内容` 或 `角色名：[VO] 内容` — 画外音（慎用）
- `[OS] 内容` — 画外/屏外声源（慎用）
- 本集场景编号从 S01 重新开始

### 对白手艺

- 每人每轮 1–2 句，少解释、多交锋；单句优先 ≤15 字
- 潜台词优先：表面说 A，实际在争 B
- 角色语言指纹要区分（口癖、节奏、用词）
- 禁止用台词复述镜头里已能看见的信息
- 禁止「说明文对白」（把人物关系/背景直接念给观众）

### 内容量参考

相对原文可压缩叙述、略增对白回合；总字数不必膨胀。同一节拍并进一场。打戏按一次交锋的结果拆开，不要缩成一句，也不要把看手机、打字、反应拆成一场一个动作。拆场前用「时长估算」累加对白与动作秒数。

## 改写步骤

1. 调用 `read_episode_script` 读取原始内容
2. 从原文第一段标到最后一段（含开篇钩子、打戏）；先列出戏剧节拍，一场一拍，不要按秒数凑场次
3. 调用 `rewrite_to_screenplay` 获取原文与衔接上下文后，**按本 skill 格式自行改写**
4. 自检：开头未跳过；删掉任一场后情节或情绪会缺一块；没有反应场、重复计划、不足 10 秒孤场、清单逐条；打戏未删未糊；对白单句不过长；按「时长估算」每场约 10–12 秒、未误超 15 秒；相邻落点可合并的已合并
5. 调用 `save_script` 保存最终结果

## 注意事项

- 心理描写 → 语气括号或一句反击台词，不要内心独白段落
- 环境信息尽量塞进场景头 + 一行动作，不要单独写景
- 每场一个落点。落点相同的动作写在同一场，不要为了凑场数再拆；不足 10 秒并场，按「时长估算」累加后不要拖过 15 秒；同一计划只留一个载体
- 打戏按一次交锋的结果拆开，禁止「一番苦战后」；不要把日常微动作也这样拆
- 保持角色语言风格一致
- 时间段要具体（黄昏、深夜、清晨），不要写「白天」

## 跨集衔接（第 2 集起）

`read_episode_script` / `rewrite_to_screenplay` 会附带上一集结尾。

1. 先读懂上一集结尾的人物位置、情绪、未完成动作
2. 本集开场用 **一句动作 + 对白接话** 过渡，不要重讲上集
3. 称呼、关系、已揭示信息与上一集一致
4. 若上一集上下文为空，仅按本集原文改写
